How the responsibilities are divided

AUTHORED ARCHITECTURE DIAGRAM

This HTML diagram explains ownership; it is not an application screenshot or an inference result. Graph and session contracts belong to the workflow service. Scheduler policy owns admission and task execution. Runtime hosts own model loading and execution, while the model library provides artifact and load-target facts.

  1. Workflow serviceValidated graph, immutable run snapshot, typed inputs and outputs
  2. SchedulerAdmission, task attempts, lifecycle evidence and resource policy
  3. Runtime host / inference adapterBackend-specific loading, readiness, execution and cleanup
  4. Model libraryPackage identity, artifacts and load-target resolution

The recorded demo exercises the service and non-runtime task path. It does not load an inference backend.
