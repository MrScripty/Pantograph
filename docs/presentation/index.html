Keep orchestration separate from model execution

ARCHITECTURE · NOT AN INFERENCE RESULT

Graph and session contracts belong to the workflow service. Scheduler policy owns admission and task execution. Runtime hosts own model loading and execution, while the model library provides artifact and load-target facts.

  1. Workflow serviceValidated graph, immutable run snapshot, typed inputs and outputs
  2. SchedulerAdmission, task attempts, lifecycle evidence and resource policy
  3. Runtime host / inference adapterBackend-specific loading, readiness, execution and cleanup
  4. Model libraryPackage identity, artifacts and load-target resolution

The deterministic demo exercises the service and non-runtime task path. It does not load an inference backend. Unpublished Pumas fixes and model tests on the developer's computer are outside this checkout and outside this evidence.
